## Files

Config: `ab-q2_0-static.json`, the base config every `ab_probe.py` and `kl_prompt.py` run read (`/ab/cfg/ab-q2_0-static.json` in the scripts; the engine arguments, the model and pack paths inside the container, `lib_dirs`), as `ab_probe.py` recorded it in each run's `meta.json`; `make_ab_config.py` made it from the run config `strata launch` had written. Scripts (scratch tools, not in the repository): `ab_probe.py` (tools/ab_engine.py's method - a fresh engine per start, alternating or rotating arm order, one warm-up, numbers from the server's `timings` - with a per-arm environment, per-arm `server=`, fresh prompts of several sizes), `kl_prompt.py` (first-token logits of long prompts through `--serve` and `STRATA_DUMP_FIRST_LOGITS`; KL and top-1 between arms), `make_ab_config.py`, `build_engines.sh` + `builder.Dockerfile` (every engine built the same way: nvidia/cuda:13.0.0-devel, nvcc V13.0.48, sm_120, the release line's options), and the scripts `step4.sh` .. `step9.sh` with the exact `docker run` lines (`<gpu-host>` stands for the machine's name).

Results: `step4-kernel-test.log`, `step4-ab-summary.txt` + `step4-ab-rows.jsonl` (stock / base / q2n with `--prefill auto`), `step4-boot-lines.txt` (each arm's engine command line, chunk and ring); `step5-ab-summary.txt` + `step5-ab-rows.jsonl` (the fixed-chunk A/B), `step5-boot-lines.txt` (the "5632 -> 2816" line of the b5632 arm); `step6-kl-vs-fp16.txt`, `step6-kl-vs-mmq.txt` (40 fresh prompts = 38 distinct token sequences, prompt cache off; the PR's 30-prompt figures leave out the four 1,024-token prompts, which the engine read as a 1,023-token chunk, below the 1,024-token floor from which every expert streams and the fused path can run, so both arms ran MMQ on them and their logits are identical, and the four 5,000-token prompts, which the MMQ and FP16 arms read as 4,864 + 136 while the fused arm read each as one chunk (logged `chunk=4999`; its configured chunk is 5,632), so those arms differ in chunking too); `step7-ctest.log`, `step7-kernel-test.log`, `step7-kl-identity.txt`, `step7-kl-final-vs-q2n.txt`, `step7-vs-step6-sha256.txt`; `step8-ctest.log`, `step8-switch-checks.txt`, `step8-engine-alone.txt`; `ptxas-sm120.txt` (the register and spill counts the commit message quotes).

`*-rows.jsonl`: one line per request (round, arm, req, decode, prompt = tok/s, prompt_n, cache_n, predicted_n, draft counts, sha of the reply). `*-summary.txt`: medians per arm and probe, paired per-round ratios, boot profile per start, the engine command line per arm.
